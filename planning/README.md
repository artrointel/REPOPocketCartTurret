# MiniTurret 개발 범위

현재 단계는 REPORaiseToUpgrade와 동일한 모드 개발 환경을 준비하는 것입니다.

- BepInEx 플러그인 식별자: `artrointel.MiniTurret`
- 초기 버전: `0.1.0`
- Harmony 패치 등록 및 종료 시 해제
- 로컬 SDK, 게임 참조, 빌드·배포·디버깅 작업
- Thunderstore 패키징

터렛의 생성 방식, 조준·발사 동작, 피해량, 구매·배터리 규칙과 멀티플레이 설치 범위는 아직 결정하지 않았습니다. RaiseToUpgrade의 게임 기능이나 방장 전용 동작은 이 프로젝트에 포함하지 않습니다.

수동 확인 항목은 [test-plan.md](test-plan.md)를 참고하세요.
